HTML Basics Quiz

1. Which tag is used to create the largest heading in HTML?

C. <head>
D. <h6>

C. <src>

B. <ul>
C. <li>

5. Which attribute specifies the type of an ordered list?

C. list-type

C. <tr>

A. <i>
B. <b>
C. <u>
D. <bold>

8. Which tag is used to create a line break?

A. <br>
B. <lb>
C. <break>
D. <hr>

9. Which tag defines the body of an HTML document?

A. <html>
B. <head>
C. <main>
D. <body>

10. Which attribute is used to change the background color of a page?

A. background-color
B. bgcolor-style
C. page-color
